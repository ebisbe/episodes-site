A little help with Episodes

The Google Play release and its dedicated support mailbox are being prepared. You can use the public issue tracker below for general questions and bug reports.

Report a problem

Open a support issue with your Android version, Episodes version, and the steps needed to reproduce the problem. The app version is shown in About.

Issues are public. Please leave out personal information, backup files, private notes and payment details. An email option for private support will be added before launch.

Move from the original F-Droid app

  1. Keep the old app installed and use its backup/export command to save your library somewhere accessible.
  2. Install the new Episodes app separately. Its application ID is io.github.ebisbe.episodes; the original is com.redcoracle.episodes.
  3. In the new app, choose Restore from backup and select the exported file.
  4. Check your shows, progress and notes before removing the old app. Configure your settings again as needed.

Restore replaces the current library rather than merging two libraries. Back up the destination library first if it already contains shows. Historical backup formats are supported through schema migrations; keep the original file if an import fails and contact support. Builds using the previous development ID com.ebisbe.episodes also require this transfer.

Back up before changing phones

Use Back up library in the menu and choose a file location you control. Copy that file to your new phone or select it through your cloud-storage provider, then restore it. Manual backups contain personal notes and should be kept private. Android system backup may also help, but depends on your device settings.

Find shows on your streaming services

Set Settings → Watching country, then use the TV-shaped streaming-services button to select providers. It filters shows already in your library, using subscription availability from JustWatch via TMDB. Rentals and purchases are excluded, and an offer for a series does not guarantee every season is available.

Information looks out of date?

Use Refresh show to update a series. Archived shows have an Update information action and are excluded from scheduled and bulk updates. Settings controls automatic refresh and network restrictions. Opening previously saved information does not refresh it just because time has passed.

Can I watch shows or connect Trakt?

Episodes does not stream video and currently has no Trakt synchronization. It keeps a local record of your progress and provides file-based backup and restore.

Purchases and refunds

Once the app launches, the upfront purchase will be handled by Google Play. Reinstall using the Google account that bought the app. Refund requests follow Google Play's refund process; this app has no subscription to cancel.
